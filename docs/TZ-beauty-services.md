# ТЗ: расширение HAIR STUDIO — ногтевой сервис и косметология

Документ дополняет основное ТЗ редизайна. Все цифры — модельные ориентиры демо-концепта, а не прайс реальной студии.

## 1. Задача

Добавить к ателье цвета два направления — **ногтевой сервис** (маникюр, педикюр) и **эстетическую косметологию** — так, чтобы сайт остался витриной ателье, а не «салоном всего подряд». Волосы и цвет остаются главным; новые направления подаются как продолжение того же принципа: сначала разговор и диагностика, потом работа.

## 4. Что появляется на сайте

1. **Каталог услуг** из 14 позиций в трёх направлениях (волосы, ногти, косметология): фильтр по направлению, по длительности, сортировка по цене; карточка с ценой «от», длительностью и составом; быстрый просмотр; запись с подстановкой услуги.
2. **Карусели:** семейства оттенков волос (атлас), формы стрижек, палитра покрытий для ногтей.
3. **Мастера:** к трём демо-профилям добавляются мастер ногтевого сервиса и косметолог-эстетист (демо).
4. **Запись:** шаг «длина волос» показывается только для услуг для волос, шаг «оттенок» — только для окрашивания и тонирования; добавлен шаг «мастер».
5. **FAQ:** можно ли совместить окрашивание и маникюр; делает ли студия инъекции (нет).

## 5. Ограничения и честность

- Имена мастеров, стаж, цены, длительности и палитры — демо. Пометки «демо» и «ориентир, а не оферта» сохраняются.
- Косметология — только эстетические уходовые процедуры. Инъекции, лазер и аппаратные методики не заявляются: для них нужна медицинская лицензия.
- Условий оплаты, отмены, гарантий и акций нет — блок-заглушка [условия уточняются].
- Перед запуском реальной студии: заменить данные в `config.js`, подтвердить прайс, для косметологии — проверить требования к лицензии и противопоказаниям.
