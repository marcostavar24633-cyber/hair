# HAIR STUDIO — «Ателье цвета»

Демонстрационный проект: одностраничный концепт премиальной студии волос в Ульяновске. Стек — HTML, CSS и vanilla JavaScript без сборки и зависимостей. Публикация — GitHub Pages.

Сайт: https://marcostavar24633-cyber.github.io/hair/

## Концепция

- **Идея:** «ателье цвета». Студия говорит о волосах как колорист: оттенок, форма, свет.
- **Палитра:** тёплая слоновая кость, чернила и медь. Все цвета — CSS-переменные в `:root` (`styles.css`). Пары текст/фон проверяются тестом на контраст WCAG AA.
- **Типографика:** Prata — дисплейный шрифт с высоким контрастом штрихов, Onest — текстовый гротеск. Оба поддерживают кириллицу и имеют системные запасные шрифты.
- **Фирменный мотив:** арка, как силуэт зеркала в салоне. Используется в фото первого экрана, услугах, атласе, портретах мастеров и знаке бренда.

## Структура страницы

1. Первый экран: заголовок, фото в арке, вращающийся знак и переключатель оттенков, который подкрашивает фото.
2. Философия: слова манифеста «проявляются» по мере прокрутки.
3. Услуги: список из шести направлений с ценами. Слева закреплённое фото, оно меняется при наведении на строку.
4. **Атлас оттенков**: шесть семейств цветов (вкладки с поддержкой клавиатуры). Анимированные «пряди», техника, поддержка цвета и ориентир цены. Кнопка переносит выбор в калькулятор.
5. Визуальные референсы: фильтр и полноэкранный просмотр.
6. Сравнение двух референсов слайдером.
7. Процесс: пять шагов, линия прогресса заполняется при прокрутке.
8. Калькулятор бюджета с расшифровкой расчёта.
9. Мастера, отзывы (слайдер), FAQ.
10. Демо-запись и подвал.

## Анимации

Появление блоков при прокрутке через IntersectionObserver, анимация первого экрана, «магнитные» кнопки (только для мыши) с заливкой при наведении. Ещё: параллакс фото, бегущая строка, вращающийся знак, колыхание прядей в атласе, полоса прогресса чтения. Всё на CSS и нативном JS, без библиотек. При `prefers-reduced-motion` анимации отключаются.

## Запуск

Откройте `index.html` в браузере или запустите папку через любой статический сервер (например, Live Server).

## Проверки

- `node tests/site-check.cjs` — SEO, структура заголовков, ARIA, изображения, CSP, приватность, контраст палитры.
- `BROWSER=chromium node tests/browser-check.cjs` — браузерные тесты в Chromium, Firefox и WebKit:
  - отсутствие горизонтальной прокрутки на ширинах от 320 до 1365 px;
  - меню, атлас, фильтр, сравнение, калькулятор, отзывы, форма и лайтбокс;
  - аудит axe (WCAG 2.1 AA).

Нужны `playwright` и `axe-core`. В CI всё запускается автоматически перед публикацией.

## Важно: демонстрационный проект

HAIR STUDIO — вымышленная концепция, а не существующий салон. Используются полностью вымышленные демонстрационные данные: название, адрес, почта, часы работы, мастера, стаж, отзывы и цены. Цены — модельные ориентиры по открытым предложениям рынка Ульяновска. Телефона и ссылок на мессенджеры нет, потому что реальных контактов нет.

Демо-запись позволяет выбрать только услугу, условный день и время. Полей для имени, телефона и почты нет. Данные не отправляются, не хранятся и не передаются; реальная запись не создаётся. Для настоящей записи нужен сервис онлайн-записи или обработчик заявок.

## Замена материалов перед реальным запуском

- Фото с Unsplash и Pexels замените собственными снимками с правом на публикацию (первый экран, услуги, референсы, сравнение, мастера).
- Укажите реальные название, адрес, телефон, мессенджеры, часы работы, цены и мастеров.
- Подключите запись (YCLIENTS, DIKIDI или обработчик формы) и политику обработки персональных данных.
- Замените разметку `WebSite` на `HairSalon` / `LocalBusiness` с реальными данными и уберите пометки «демо».
