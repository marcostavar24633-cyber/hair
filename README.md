# HAIR STUDIO — демонстрационный сайт для портфолио

Адаптивный одностраничный сайт парикмахерской на HTML, CSS и JavaScript.

## Запуск
1. Распакуйте архив.
2. Откройте `index.html` в браузере.
3. Для локальной разработки можно запустить папку через расширение Live Server в VS Code.

## Что реализовано
- адаптивная вёрстка для мобильных и настольных экранов;
- мобильная навигация;
- блоки услуг, работ, преимуществ и отзывов;
- фильтрация галереи;
- форма заявки с базовой проверкой полей;
- SEO title, description, Open Graph, favicon и семантическая структура.

## Перед публикацией для реального бизнеса
Замените демонстрационные адрес, телефон, расписание, цены и отзывы на подтверждённые данные владельца. Замените изображения на лицензированные фотографии салона и работ мастеров. Подключите форму к CRM/сервису записи, настройте согласие на обработку персональных данных и опубликуйте политику конфиденциальности. Добавьте реальные контакты, карту, аналитику и favicon.

Контакты и график не указаны, цены не публикуются, блок отзывов ожидает реальные отзывы. Форма записи демонстрационная.
