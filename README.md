# HAIR STUDIO — «Ателье цвета»

Демонстрационный проект: одностраничный концепт студии волос в Ульяновске. Стек — HTML, CSS и vanilla JavaScript без сборки и зависимостей. Публикация — GitHub Pages.

Сайт: https://marcostavar24633-cyber.github.io/hair/

## Концепция

- **Идея:** «ателье цвета». Студия говорит о волосах как колорист: оттенок, форма, свет. Сначала разговор и диагностика, потом работа.
- **Палитра:** слоновая кость, бумага, чернила и медь. Медь — редкий акцент (не больше четырёх мест: слово в заголовке первого экрана, активная вкладка атласа, ориентир цены и итог записи). Все цвета — токены в `:root` (`styles.css`), пары текст/фон проверяются тестом на контраст WCAG AA.
- **Типографика:** Cormorant Garamond — дисплейный шрифт с курсивом и кириллицей (акцент в заголовках — курсивом, а не цветом), Onest — текстовый гротеск. Шкала размеров 1,25, табличные цифры в ценах, русская типографика (неразрывные пробелы, «ёлочки», тире).
- **Формы:** арка (фирменный мотив, `--r-arch`) и один малый радиус `--r: 2px`. Одна форма кнопки. Иконки — собственный inline-SVG спрайт с линией 1,25 px.
- **Ритм фонов:** светлый первый экран, манифест и услуги → тёмный атлас → светлые референсы → тёмные мастера и запись → светлый FAQ → тёмный подвал.

## Структура страницы

1. Шапка: знак-арка, меню с подменю «Услуги» и мега-меню «Атлас цвета», значок «Демо-концепт», кнопка «Записаться».
2. Первый экран: заголовок в три строки, фото в арке с переключателем оттенков, три смысловых тезиса.
3. Манифест: слова «проявляются» при прокрутке.
4. Услуги: шесть направлений с ценой «от», длительностью и составом; процесс в одну строку.
5. Атлас цвета: шесть семейств оттенков, «пряди», техника, поддержка и ориентир цены. «Выбрать этот оттенок» передаёт выбор в запись.
6. Референсы: журнальный разворот с фильтром и лайтбоксом; недостающие снимки — подписанные плейсхолдеры.
7. Мастера и «Первый визит»: монограммы, таймлайн визита, что взять с собой, демо-отзывы.
8. Пошаговая запись: услуга → длина (живой расчёт) → оттенок (только для окрашивания) → день и время → итог.
9. FAQ и подвал с полной пометкой о концепте.

Блок «Сравнение» удалён: две разные фотографии ничего не доказывают. Вернуть его стоит только с реальными кейсами «до/после» и разрешением на публикацию.

## Где настраивать

| Что | Где |
|---|---|
| Цвета, шрифты, размеры, отступы, радиусы | `styles.css`, `:root` |
| Длительности и кривая анимаций | `--d-fast`, `--d-base`, `--d-hero`, `--ease` |
| Задержка «по очереди» | `--stagger` (блоки), `--menu-stagger` (пункты меню) |
| Задержка закрытия подменю | `--sub-close-delay` |
| Ширина выдвижных панелей | `.drawer-panel` (меню), `.drawer-booking .drawer-panel` (запись) |
| Шапка: скрытие, компактный и тёмный вариант | `.site-header.is-hidden`, `.is-compact`, `.is-dark`; логика — `onFrame()` в `script.js` |
| Прозрачность «приглушённых» слов манифеста | `--word-dim` (тест проверяет контраст ≥ 4.5:1) |
| Цены, длительности, коэффициенты длины | объекты `services`, `lengths` в `script.js` |
| Описания оттенков | объект `tones` в `script.js` |
| Появление при прокрутке | `revealGroups` в `script.js`, `.js [data-reveal]` в CSS |
| Отключение движения | `@media(prefers-reduced-motion:reduce)` в конце `styles.css` |

## Анимации

Появление блоков при прокрутке (IntersectionObserver, сдвиг 20 px, дочерние элементы по очереди), строки заголовка первого экрана выезжают из-под маски, фото раскрывается из арки (`clip-path`), едва заметный параллакс фото. Кнопки заливаются слева направо, ссылки прорисовывают линию. Атлас плавно сменяет «пряди», FAQ раскрывается через `grid-template-rows`. Анимируются только `transform`, `opacity` и `clip-path`, одна кривая `cubic-bezier(.22,.7,.18,1)`. Все эффекты прокрутки — в одном цикле `requestAnimationFrame`. При `prefers-reduced-motion` движение отключается, контент виден сразу. Бегущей строки, вращающегося знака, кастомного курсора, теней и 3D-наклона нет.

## Запуск

Откройте `index.html` в браузере или запустите папку через любой статический сервер.

## Проверки

- `node tests/site-check.cjs` — SEO, заголовки, ARIA, изображения (без повторов фото), CSP, приватность, контраст, стандарт люкса: цвета и радиусы только через токены, медь не больше четырёх раз, нет Unicode-стрелок и эмодзи, нет запрещённых слов и восклицательных знаков, неразрывные пробелы в заголовках.
- `BROWSER=chromium node tests/browser-check.cjs` — браузерные тесты в Chromium, Firefox и WebKit:
  - нет горизонтальной прокрутки на ширинах от 320 до 1920 px, длина страницы, заголовок в три строки;
  - мобильное меню (фокус-ловушка, Esc, подложка, ссылки), подменю (наведение с задержкой, Enter/Space, Esc), шапка;
  - атлас (стрелки, Home, End), пошаговая запись в боковой панели (подстановка выбора, «Далее»/«Назад», расчёт, пропуск шага оттенка, итог);
  - фильтр, лайтбокс, отзывы, FAQ, режим без JavaScript;
  - аудит axe (WCAG 2.1 AA) в нескольких состояниях.

Нужны `playwright` и `axe-core`. В CI всё запускается автоматически перед публикацией.

## Важно: демонстрационный проект

HAIR STUDIO — вымышленная концепция, а не существующий салон. Используются полностью вымышленные демонстрационные данные: название, адрес, почта, часы работы, мастера, стаж, отзывы и цены. Цены и длительности — модельные ориентиры. Телефона и ссылок на мессенджеры нет, потому что реальных контактов нет.

Демо-запись позволяет выбрать только услугу, длину, оттенок, условный день и время. Полей для имени, телефона и почты нет. Данные не отправляются, не хранятся и не передаются; реальная запись не создаётся.

## Замена материалов перед реальным запуском

- Провести собственную съёмку в единой арт-дирекции (тёплый мягкий свет, крупные планы прядей, руки колориста, интерьер в арочных проёмах) и заменить фото с Unsplash/Pexels и плейсхолдеры.
- Добавить реальные портреты мастеров вместо монограмм, реальные отзывы с согласием авторов.
- Указать реальные адрес, телефон, мессенджеры, часы работы, цены и длительности.
- Подключить запись (YCLIENTS, DIKIDI или обработчик формы) и политику обработки персональных данных.
- Заменить разметку `WebSite` на `HairSalon` / `LocalBusiness` с реальными данными и убрать пометки «демо».
